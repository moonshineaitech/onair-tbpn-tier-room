# Shared board cards and personal board entry

Existing `/tier-list?room=…&board=…` links now render Open Graph and `summary_large_image` metadata on the server. Crawlers receive absolute image URLs in the HTML head without running JavaScript or signing in. Newly copied links include the published update time; image URLs include a fingerprint of the public snapshot and approved segment catalog.

`GET /api/board-preview/:id` generates a 1200 × 630 PNG using the framework's `next/og` support. It reads only a visible published snapshot and approved moments. All six tiers and actual ranked/unranked counts are shown. Up to 24 rankings fit in the card; larger boards show four segments per tier and explicit remaining counts. The full board is available through the link. Bounded PNG/JPEG thumbnails come only from approved R2 image references; external URLs are never fetched by this renderer. Large or invalid images use a title-initial fallback.

Generated bytes are cached privately in R2, with one cache key per posted board. Every public image request validates visibility and the catalog fingerprint before using cached bytes or returning 304. Hidden and withdrawn boards return 404 even if an earlier image is cached. Draft edits do not alter the published card; republishing does. Copies already cached by another platform remain under that platform's caching policy.

The shared-board view has a prominent **Make my board for this show** link. It opens the same episode in My board and retains any existing personal draft. Returning viewers see **Continue my board**. These are ordinary links that support opening in another tab, with an in-page shortcut for normal clicks. Personal board URLs use `view=mine`; legacy episode aliases remain pinned for this explicit personal view. No snapshot is copied into a visitor's rankings, and the shared board is unchanged.

The sharing dialog displays the actual server-generated image. Captions credit another viewer when sharing their board. A PNG failure falls back to the existing text preview, while manual image export remains available.

Validation: 25 social-card checks, 20 existing fast interaction/sharing checks, and 24 admin/upload checks passed. Browser checks covered creation from a shared board, continuing saved personal ranks, mobile entry sizing, and the share dialog image. TypeScript and the production build passed. All mutation checks use disposable local rooms.
